# FriendsHub Frontend 🌍

Сучасний клієнтський веб-інтерфейс для платформи **FriendsHub**.

## 🚀 Стек технологій
* **Архітектура:** Single Page Application (SPA) на чистих ES-модулях (без важких `node_modules`).
* **Стилі:** Tailwind CSS + Glassmorphism design system.
* **Іконки:** Lucide Icons.
* **Шрифт:** Plus Jakarta Sans.
* **Сервер:** `python frontend/server.py` (Dual-stack IPv4/IPv6, CORS та проксі до Spring Boot API).

## 🌟 Можливості
1. **📊 Дашборд:** Швидка статистика, найближча підтверджена зустріч або активне опитування, розраховані Top-3 спільні слоти.
2. **✨ Smart Matcher (Sliding Window):**
   - Вибір учасників із друзів.
   - Бажані дні тижня (`Пн-Нд`).
   - Бажані години доби (наприклад, `17:00 - 22:00`).
   - Тривалість зустрічі (30 хв, 1 год, 1.5 год, 2 год).
   - Розрахунок Top-3 слотів із найвищим показником збігу (`POST /api/availability/calculate`).
   - Створення зустрічі-опитування для друзів (`POST /api/meeting/propose`).
3. **🗳️ Зустрічі та голосування за слоти:**
   - Голосування за запропоновані часові варіанти (`POST /api/meeting/{id}/vote`).
   - Затвердження організатором слота-переможця (`POST /api/meeting/{id}/finalize`), що фіксує точний час та синхронізує подію з Google Calendar.
   - Скасування або відхилення участі.
4. **🔄 Мій базовий ритм (Рутина):**
   - Керування повторюваним щотижневим графіком (`PUT /api/routines`): дні тижня, робочий час, тренування.
   - Автоматичне вирахування вільного часу з урахуванням рутини та Google Calendar.
5. **👥 Друзі:** Пошук, прийняття запитів, список контактів та швидке запрошення до спільних опитувань.
6. **⚡ Live API / Demo Mode:** Перемикання в 1 клік між реальними запитами до бекенду та інтерактивним демо-сховищем.

## 💻 Запуск
```bash
python frontend/server.py
```
Відкрийте у браузері: **http://localhost:5173** або **http://127.0.0.1:5173**
